## Work

### [AgriBot](https://github.com/ramkrishnaji/agribot) — Production RAG for Agriculture
Llama 3.1 (via Groq) backed by hybrid semantic search, injected with live weather and market data, delivered over WhatsApp via Twilio. Built a Together AI fallback for near-100% uptime. The interesting part was making retrieval fast enough to not feel like a chatbot.

`FastAPI` `RAG` `Llama 3.1` `Redis` `Docker` `Groq` `Twilio`

---

### [Real-Time NLP Pipeline](https://github.com/ramkrishnaji/realtime-sentiment-pipeline) — Streaming Sentiment at Scale
End-to-end streaming architecture: Kafka ingestion → Spark Structured Streaming → PyTorch classifier → Power BI dashboard. The challenge was keeping classification latency low enough that "real-time" actually meant something.

`Kafka` `Spark` `PyTorch` `Python` `Power BI`

---

### [Predictive Maintenance](https://github.com/ramkrishnaji/predictive-maintenance-ml) — LSTM on NASA CMAPSS
Multivariate sensor time-series → RUL prediction and pre-failure classification. PyTorch LSTM benchmarked against XGBoost and Random Forest. Wrapped with a FastAPI inference endpoint so it's actually usable.

`PyTorch` `LSTM` `scikit-learn` `FastAPI` `Pandas`
